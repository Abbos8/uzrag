# UzRAG

A production-oriented Retrieval-Augmented Generation (RAG) system for the Uzbek language.

> Work in progress — built in public over 4 months.
> Follow the journey: [Telegram channel link](https://t.me/ai_insights_uz)

## Goal
Answer questions over Uzbek-language documents using hybrid retrieval,
reranking, an agent layer, and a full evaluation harness.

## Status
Week 1 — Project setup and foundations.

## Stack (planned)
- Python
- Vector DB: Qdrant
- Retrieval: dense + BM25 (hybrid) + reranking
- Orchestration: LangChain / LangGraph
- API: FastAPI
- Evaluation: RAGAS + custom metrics (Recall@K, MRR, nDCG)
- Observability: Langfuse
- Packaging: Docker
